# CA3 · Causal reasoning

[← All projects](../README.md) · [Report](CA3_report.pdf) · [Assignment specification](TAI_CA3_Description.pdf)

[Open the notebook](CA3.ipynb)

This assignment implements a structural causal model (SCM) and explores causal questions through course-effect and smoking examples. The website engagement section compares naive analysis with causal modeling and includes a placebo test.

Run from `CA3/` with the root [Python dependencies](../README.md#getting-started) installed. The notebook uses NumPy and pandas for data, NetworkX for graph structure, statsmodels for regression, and Matplotlib for visualizations.

`website_engagement_data.csv` is included beside the notebook. Run the SCM implementation cells before the later examples, which reuse those definitions.
